## 买腾讯云免备案服务器前，容易忽略什么？

最容易忽略的是这几件事：免备案不等于免实名、入门型不保障跨境质量、腾讯云 CDN 仍需备案、活动价和续费价不是一回事。

1. **免备案不等于免实名。** 域名要完成实名认证，账号实名按腾讯云当前规则走。备案和实名是两条线，别因为买了香港服务器，就以为域名可以完全匿名。
2. **入门型便宜，但不保障跨境质量。** 香港入门型的套餐说明明确不保障内地与香港之间的公网质量。访客在大陆，优先锐驰型或通用型；入门型更适合香港本地或海外访客。
3. **源站在香港，不代表腾讯云 CDN 不用备案。** 腾讯云备案文档写明，使用腾讯云 CDN 的域名需要先完成备案。想用 CDN 给香港服务器加速，这一步要提前算进计划。

5. **香港节点不参与大陆备案。** 香港服务器不需要备案，但它也不是大陆备案资源；以后把域名解析回大陆服务器，要按大陆接入重新办理备案。
